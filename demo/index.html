This page has been made to demonstrate the features of UnrealPackageReader.js, a file reader written in TypeScript which can read data from Unreal Tournament packages (as well as several other Unreal Engine 1 games).

This page would not have been possible without the following FOSS projects:

  • DataTables - displays various tables (Sounds, Scripts, Import/Export Objects, etc.)

  • three.js - renders meshes, brushes, and map previews

  • WebXmp - tracker music file playback

  • JSMpeg - MP2 audio playback

  • vgmstream - XA audio decoding algorithm

  • highlight.js - syntax highlighting for Scripts tab

  • jQuery - misc. page functionality
